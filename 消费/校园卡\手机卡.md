# 校园卡

校园卡，说白了就是一张**手机 SIM 卡**，通常还会搭配校园网套餐。

## 运营商与办理规则

校园卡的办理规则会因校区、年份和运营商而有所不同，具体以当年的实际政策为准。

以今年江淮校区的情况为例：

- **中国移动、中国联通：** 有校园卡套餐。
- **中国电信：** 今年没有参与。

至于电信为什么没有参与……可能是因为福利太好，被排挤了？（纯属猜测，别当真。）

## 价格与套餐

今年江淮校区的校园卡套餐如下：

| 项目 | 内容 |
|---|---|
| 月费 | ¥49/月 |
| 校园网 | 包含在套餐内 |
| 首充要求 | ¥100 |
| 校内流量 | 200GB/月 |
| 校外流量 | 15GB/月 |
| 通话时长 | 200 分钟/月 |

**关于月费：** 实际上，校园卡为 ¥39/月，校园网为 ¥10/月。由于办理校园卡必须同时购买校园网，不能分开办理，因此这里直接按 ¥49/月的整体费用计算。

## 附赠福利

办理后，前 12 个月每个月还可以领取一个平台的 VIP 会员，具体可选平台以当年活动规则为准。

可选范围包括各大音乐平台、视频平台和购物平台等，具体有哪些，大家可以自行探索。

## 一点个人评价

**200GB 校内流量，真的用得完吗？**

相信我，光是基础套餐里的 200GB 校内流量就已经相当充足了。再加上各种额外赠送的流量，基本不用担心流量不够用——甚至可能会想办法把流量用掉。

不过，以上是今年江淮校区的情况。不同年份的套餐、赠送福利和办理要求可能发生变化，办理前记得核实最新政策。
