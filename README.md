# NCWU-info-For-Surviving-Better

> **献给所有华水学子，特别是新生。**

这是一个由学生维护的、**非官方的华水生存指南**。

这里汇聚那些你可能不知道、学校也未必会主动告诉你的信息——尤其是与**日常生活、校园资源、消费、住宿、办事和避坑**有关的内容。

我们的目标很简单：

> **让每一个 NCWUer，都能少走一点弯路，更好地在华水活下去。**

---

## 📖 这里有什么？

本项目不追求“官方”，而追求：

- **真实**：来自学生实际经历与调查
- **实用**：解决真正影响校园生活的问题
- **具体**：尽量给出地点、价格、时间、规则等明确答案
- **可验证**：尽可能提供证据、来源或实地验证信息
- **持续更新**：华水会变，这个项目也会跟着变

例如：

### 💧 饮用水

**宿舍里的水是不是必须付费？**

如果你不想花钱买水：

- 哪些地方可以免费接饮用水？
- 每个校区分别在哪里？
- 不同宿舍区有没有区别？
- 为什么有些地方收费，有些地方免费？
- 有没有隐藏的免费水源？
  
并且会总结：

> **华水的免费饮用水设点的规律是什么**
> 以保证就算校区变化，也能找到新的免费饮用水点位

## 🔍 我们记录的不只是“答案”

本项目希望尽可能回答三个问题：

**① 发生了什么？**

> 宿舍饮用水需要收费。

**② 有没有替代方案？**

> 有。某教学楼 / 某宿舍区存在免费饮水点。

**③ 为什么会这样？规律是什么？**

> 某类设施为什么收费？哪些地方通常可以找到免费资源？

也就是说，我们不仅记录**“哪里有什么”**，也尝试总结**“华水是怎么运行的”**。

## 🤝 贡献信息

这是一个由学生共同维护的项目。

你可以贡献：

- 一个地点
- 一条经验
- 一张照片
- 一份价格记录
- 一个办事流程
- 一次踩坑经历
- 一个学校没有明确说明的规则
- 或者任何你认为**“其他华水学生应该知道”**的信息

**不要害怕信息太小。**

“某栋楼三楼有免费饮水机”这种信息，同样非常有价值。

提交信息时，尽量说明：

- 📍 地点
- 🕐 时间
- 💰 价格
- 📷 证据 / 照片（如有）
- 📅 信息更新时间
- 📝 具体情况
