# NCWU-info-For-Surviving-Better

> **献给所有华水学子，特别是新生。**

这是一个由学生维护的**非官方华水生存指南**，收录那些你可能不知道、学校也未必会主动告诉你的信息——尤其是**日常生活、校园资源、消费、住宿、办事和避坑**。

目标很简单：

> **让每一个 NCWUer 少走一点弯路，更好地在华水活下去。**

---

## 📖 这里有什么？

我们追求：

- **真实**：来自学生实际经历与调查
- **实用**：解决真正影响校园生活的问题
- **具体**：尽量给出地点、价格、时间、规则等明确答案
- **可验证**：尽可能提供证据、来源或实地验证信息
- **持续更新**：华水会变，这个项目也会跟着变

---

## 🔍 我们记录的不只是“答案”

每条信息尽量回答三个问题。以「宿舍饮用水要收费」为例：

**① 发生了什么？**

> 宿舍里的水必须付费。

**② 有没有替代方案？**

> 有。哪些教学楼 / 宿舍区有免费饮水点，各校区分别在哪里，不同宿舍区有没有区别，有没有隐藏水源。

**③ 为什么会这样？规律是什么？**

> 哪些地方通常能找到免费资源，华水免费饮水点位的设点规律是什么——这样即使校区变化，你也能自己找到新的免费水。

也就是说，我们不仅记录**“哪里有什么”**，也尝试说清**“华水是怎么运行的”**。

## 🤝 贡献信息

这是一个由学生共同维护的项目。你可以贡献：

- 一个地点
- 一条经验
- 一张照片
- 一份价格记录
- 一个办事流程
- 一次踩坑经历
- 一个学校没有明确说明的规则
- 或者任何你认为**"其他华水学生应该知道"**的信息

**不要害怕信息太小。**

"某栋楼三楼有免费饮水机"这种信息，同样非常有价值。

提交信息时，尽量说明：

- 📍 地点
- 🕐 时间
- 💰 价格
- 📷 证据 / 照片（如有）
- 📅 信息更新时间
- 📝 具体情况
- 为什么推荐

另外，这个项目几乎全是 md 文件，很多同学不会写格式，可以先写草稿，然后丢给 AI 整理（推荐优先用 ChatGPT，不仅是因为免费版可无限使用，而且因为本项目正文也是用 GPT 写的，风格会更类似。当然用豆包、千问、DeepSeek 等 AI 也完全 OK）。
